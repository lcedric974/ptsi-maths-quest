Héberger PTSI Maths Quest sur Vercel

Application 100% statique (Zero-Config) prête en moins de 2 minutes

1 Télécharger les fichiers prêts pour Vercel

Cette application est autonome dans un unique fichier index.html. Vous pouvez également télécharger le fichier optionnel vercel.json pour les en-têtes de sécurité et de cache optimaux.

2 Option A : Déploiement sans ligne de commande (Drag & Drop / GitHub)
  1. Placez index.html (et vercel.json) dans un dossier nommé ptsi-maths-quest.
  2. Créez un dépôt sur GitHub et importez-le sur vercel.com/new (Framework Preset : Other).
  3. Cliquez sur Deploy : votre URL .vercel.app est immédiatement en ligne !
3 Option B : Déploiement express via Vercel CLI 
npx vercel --prod
